Workflow

LangGraph 状态图工作流

使用 LangGraph StateGraph 构建条件路由图。fast_context 并行采集后，根据意图与验证模式动态路由到 Teacher / Examiner / Verifier / Proof Tutor，MemorySaver 提供检查点恢复。 

from langgraph.graph import StateGraph, END, START

workflow = StateGraph(AgentState)
workflow.add_node("fast_context", self.fast_context_node)
workflow.add_node("teacher", self.teacher_node)
workflow.add_node("verifier", self.verifier_node)
workflow.add_node("examiner", self.examiner_node)
workflow.add_node("proof_tutor", self.proof_tutor_node)
workflow.add_node("policy_fallback", self.policy_fallback_node)

workflow.add_edge(START, "fast_context")
workflow.add_conditional_edges(
    "fast_context", route_after_context,
    {
        "teacher": "teacher",
        "verifier": "verifier",
        "examiner": "examiner",
        "proof_tutor": "proof_tutor",
        "policy_fallback": "policy_fallback",
    },
)
workflow.add_edge("verifier", "teacher")
workflow.add_edge("teacher", END)
workflow.add_edge("examiner", END)
workflow.add_edge("proof_tutor", END)

graph = workflow.compile(checkpointer=MemorySaver())

# 普通请求: fast_context → teacher → END  (1×LLM)
# 验证请求: fast_context → verifier → teacher → END  (2×LLM)
Verification

SymPy 符号验证引擎

大模型在数学推导中存在概率性幻觉。SymPy 作为 Python 符号数学库，提供确定性的表达式等价校验—— simplify(lhs - rhs) == 0 从根源上消除幻觉风险。 

from sympy import symbols, diff, simplify
from sympy.parsing.sympy_parser import (
    parse_expr, standard_transformations,
    implicit_multiplication_application, convert_xor,
)

# 学生输入 "2x" 自动解析为 2*x
TRANSFORMS = standard_transformations + (
    implicit_multiplication_application, convert_xor,
)

def verify_equivalent(lhs: str, rhs: str) -> VerifyResult:
    """验证两个数学表达式是否等价"""
    lhs_expr = parse_math(lhs)   # LaTeX → SymPy
    rhs_expr = parse_math(rhs)
    diff = simplify(lhs_expr - rhs_expr)
    ok = diff == 0                # 确定性判断
    return VerifyResult(verified=True, is_correct=ok)

def verify_derivative(expr, var, expected):
    derivative = diff(parse_math(expr), Symbol(var))
    ok = simplify(derivative - parse_math(expected)) == 0
    return VerifyResult(verified=True, is_correct=ok)

def verify_integral(integrand, var, candidate):
    # 对候选结果求导，与被积函数比较
    deriv = diff(parse_math(candidate), Symbol(var))
    ok = simplify(deriv - parse_math(integrand)) == 0
    return VerifyResult(verified=True, is_correct=ok)

Pedagogy

BKT 贝叶斯知识追踪

摒弃简单"正确数/总数"算分。基于四参数隐马尔可夫模型动态更新掌握概率 P(L|obs)， P(G)/P(T) 根据提示依赖度自适应调整，防止"被动喂饭"导致分数虚高。

$$P(L_{n+1}) = P(L_n) \cdot (1 - P(S)) + (1 - P(L_n)) \cdot P(G)$$

掌握度更新公式：已掌握且不失误 + 未掌握但猜中（含知识转移 P(T)）

Streaming

SSE 流式输出与事件序列

基于 HTTP 长连接的单向流式协议。服务端按事件序列持续推送——opening 快速开场、thinking 摘要、meta 路由元数据、message 逐 token、done 收尾指标。前端用 fetch + ReadableStream 消费，支持自定义 Header 携带 API Key。

opening < 150ms 本地快速开场白，不等待 LLM
thinking 采集中 [隐式RAG] [VERIFY] [OUTPUT] 摘要
meta 路由后 意图 / 学科 / 概念 / 掌握度
message 流式 逐 token 回答（过滤 reasoning）
done 收尾 metrics / route / llm_call_count

为何 SSE 而非 WebSocket

单工场景 + 标准 HTTP + 自动重连 + 穿透代理更可靠，无需协议升级

reasoning 过滤

模型内部思考链不向学生暴露，防止答案直接泄露，保证启发式教学

fetch 替代 EventSource

EventSource 不支持自定义 Header，用 fetch + ReadableStream 解析 SSE 帧以携带用户 Key

Retrieval

BM25 + 向量混合检索

本地 BM25 全文检索先行（零延迟、精确概念匹配），语义向量搜索作为后台异步任务预热缓存（覆盖同义/近义表达）。350ms 截止，超时自动取消，部分结果仍可用。

BM25 本地检索

基于词频的全文检索，零网络延迟。适合精确概念匹配（如"洛必达"、"特征值"），结果即时可用。

语义向量搜索

调用 LLM Embedding API 计算语义相似度，覆盖同义/近义表达。后台异步执行，LRU 缓存 128 条预热下一轮。

融合策略

BM25 先行（350ms 截止），向量搜索异步预热。直接命中 + 图谱扩展双路融合，返回 EvidencePack。
