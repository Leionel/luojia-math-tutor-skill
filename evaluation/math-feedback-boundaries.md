# 数学反馈边界：精确小数与判词冲突

以下是从 `accd40d` 复现并修复的确定性反例。它们属于公开开发回归，不能据此估计未见题或真实模型的错误率。

## 十进制字面量丢失

原链路先读取 Python AST 的浮点值，再转有理数；输入精度已在第一步丢失。

| 输入 | 独立算术依据 | 修复前 |
| --- | --- | --- |
| `1.0000000000000001=1` | 左右差为 `1/10^16`，不相等 | 判为正确且允许作为学习证据 |
| `0.10000000000000001=0.1` | 左右差为 `1/10^17`，不相等 | 判为正确 |
| `\|0.10000000000000001 0;0 1\|=0.1` | 行列式等于左上元素，与右侧差 `1/10^17` | 矩阵先转 float，判为正确 |

修复保留词法原文，经 Decimal 位数和指数预算检查后构造精确 Rational。矩阵抽取也保留数字字串；极端指数、位数或非有限数返回 unknown，避免大整数分配。核验器版本升为 `step-v2`。

## 模型反向判错

在 `d(x^2)/dx=2*x` 已获得匹配输入的确定性正面核验时，旧 `TeachingDecision` 仍接受 `contradicted + correct_claim`，即使它引用的正是该核验结果。旧交付检查也未阻止“这一步不对”这类明确反向判词。

修复分两层：决策层对完整当前候选的相反结论触发降级；交付层对部分明确判词触发既有一次修复，重复冲突则不交付。历史版本、错绑输入、参考计算或范围不完整的结果不参与这个约束。引文、假设句及否定引用不应被当作新的错误判词。
