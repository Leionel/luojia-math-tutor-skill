# R6.2 / R6.3 实施与验收

日期：2026-10-17。起点 `47d60bc1d1971e76f6337404fbb1f83b9345b9bf`，分支 `feature/course-graph-2.0`。工作树已有 R6.1 与无关 R2/UI 改动；先将本轮之前的 R6.1 文件独立提交为 `3aba7c8`，保留无关改动。R6.2 主实现提交为 `de03fd3`，R6.3 及边界补充为 `ff8c318`，文档与验收回执另行提交。

## 原缺口与原因

R6.1 已有 GS/Newton 的主张、真实 runner、预测、历史修订、私人图、显式 Chat 引用和加宽网络。缺口是消费边界：旧历史只能由用户显式打开原探索后进入 Chat；新问题没有按相关性检索。模型候选没有逐条 pending/接受/拒绝及版本化回执。积分已在 numerical-lab 保存并支持引用，但未进入持续探索。

此前真实模型六次调用不是“已经通过”：第一批三次都在 1536 输出 token 上截断；关闭推理后的第二批，GS 没设计出预期反例实验，Newton 同时出现 action/实验字段冲突及悬空候选端点，缺条件案例又把未指定的比较量补成残差。Newton 还给出不可靠的吸引域分界建议。回执见 [R6.1 报告](r61-execution-report.md)及本机 `results/r61/live-review.json`。根因包括输出预算/协议过重、可选候选图与教学建议绑定过紧，以及模型数学判断失误。

本轮将候选图独立校验：无效端点或编造来源会舍弃候选并提示，不丢弃其余有效建议。action 与计划冲突仍拒绝，避免替模型猜测教学动作。提示区分普遍主张的反例设计与具体问题缺参数，也明确 Newton 吸引域、积分估计的限制。**这些提示修改尚无新增真实模型成绩。**

## 数据流与主要修改

`CourseStore.learning_records` → 同一 owner/course、近期 50 条、按问题筛选 → 最多两条私人关联与每条一项相关计算、总计 7 KiB → 原 Chat 编排 `personal_context` → 原 `TeachingDecision.source_bundle` → 回答消息持久化 → 可刷新的选择理由和原探索链接。每条保留探索 ID/revision、关系 ID/内容版本、权威类别、原意见、最新修订、选择理由和原引用。无来源事实仍是私人意见；官方来源保持其审核等级。

关系提议在原探索中默认 pending；编辑、接受、拒绝有候选版本、探索版本、幂等操作标识与持久化回执。接受只加入私人图，不改课程图、verified 或独立掌握。来源失效则排除该关联；已选计算失效则记录原定位，不自动改用另一条计算。交付前再次核对选取的版本和来源。

`ExperimentPlan` → 可编辑领域参数/保持与变化因素/数学理由/工具限制 → 学生预测与确认 → 原探索事务 → `exploration_runner` 薄适配 → 原 root/numerical runner 与原实验存储 → 同一探索历史、修订及规范引用。前端三类表单的字段与转换在 `lib/experiment-plans.ts`，共用一个编辑组件和 Explore 页面。

## 相关与不相关对照

[实际离线对照回执](r62/offline-comparison.json)保留所选上下文、TeachingDecision、source hash 和交付正文。无私人上下文时，夹具追问函数、初值与收敛条件；有上下文时，同一 Chat 路径引用 `personal:0`，联系原来的“任意初值都收敛”、后来修订和 0/1 循环，追问本题局部条件。两次都用模型 fixture，证明编排差异，不能声称教学质量改善。

SQLite 持久化回归覆盖：积分与 GS 新问题不消费 Newton 旧关系；来源笔记改版后不作为依据；计算记录失效不替换其他旧计算；重开数据库结果一致；不同用户不可读；过期候选版本拒绝；接受/拒绝幂等回执；官方课程数据与掌握记录不受私人决定影响。

## 三条真实 runner 案例

完整输入、编辑后的计划、预测、计算轨迹及修订见 [本地计算回执](r63/local-run-receipts.json)，案例配置见 [cases.json](r63/cases.json)。计划选择使用 fixture，计算来自真实受控 runner。

| 案例 | 输入与工具 | 实际证据 | 保存的修订 |
|---|---|---|---|
| GS | 两个二阶矩阵，改变 matrix，原 Gauss-Seidel runner | 第一组谱半径 1/12；第二组不严格行对角占优，谱半径 1/5，末残差约 9.216e−7 | 严格行对角占优是充分条件，不是必要条件 |
| Newton | x³−2x+2，初值 0、−2，原 Newton runner | 0→1→0；−2 在 4 步后函数值约 −5.054e−13 | 排除“任意初值收敛”；循环可代数核对，残差达标不证明吸引域边界 |
| 积分 | x⁴，[0,1]，Simpson 初始分段 4、8 | 编辑后均细分 3 次，末近似值 0.2000001271565755 / 0.20000000794728595；估计不是严格界 | 步长对照只支持局部数值观察 |

另测 `sin(8*pi*x)^2` 在 [0,1]：光滑函数的网格混叠导致极小估计与约 1/2 的实际误差并存，`error_bound` 保持空值。不能把估计阈值当严格误差证明。无矩阵的具体 GS 判定、多元/复数 Newton/Python、缺独立条件的严格积分误差界均有“不提实验”的协议回归，未自动生成伪参数。
