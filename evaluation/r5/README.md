# R5 数学教学质量：材料与离线采集

## 当前能回答什么

24 个公开开发案例覆盖局部正确与整体结论、条件缺失、证明充分性、合法方法、残差/步差、工具冲突、错误定位及跨算法迁移。每题包含原话、前提、推导、允许/禁止结论、建议动作、unknown 边界、版本和摘要。

全部材料为 `agent_prepared_only`，待作者与独立审核。6 个保留题名额没有题目或答案，应由独立作者提供并封存；公开开发题不能再称未见保留集。

**固定回复不能回答 Agent 是否优于普通 LLM。** 当前交付的是可运行的编排消融与证据采集，不是性能结论。

## 运行

```powershell
python scripts/eval_r5.py --offline --output results/r5/my-offline-run.json
```

运行实际 ASGI/SSE 路由与编译工作流。每题每组采用独立临时学生库、课程库和合成身份；模型函数被替换，外部 HTTP/socket 拒绝。全量计划 24×3 次。可用 `--case E01` 做局部诊断，其他计划项保留 not_run，全量验收仍显示未完成。

聚合 JSON 保存覆盖、回执、来源摘要与逐运行 artifact 引用；artifact 保留完整公开输入、固定输出、SSE、教学决策和学习写入，并以 SHA256 绑定，避免超过 S5 的 2MB 读取上限。同名 Markdown 给出覆盖与边界。任何失败或未知保留；usage 和费用为 null，固定回复不伪造 token 数。整体采集进程有 300 秒硬超时，3 次模型 fixture 调用上限；25 秒是耗时观察阈值，不是已实现的逐请求硬停止。

## 三组干预

| 组 | 内容 | 与正式产品的关系 |
| --- | --- | --- |
| D0 | 合理普通数学教学提示，关闭项目数学检查、检索与教学决策 | 通过应用路由，harness 控制提示和功能干预 |
| D1 | 与 D0 相同提示，加当前有限核验回执 | 数学工具沿用当前 checker，失败与范围照实传递 |
| D2 | 原生项目上下文、课程检索和教学决策 | 应用原生提示与路由，模型仍是固定 fixture |

干预仅在采集子进程 monkeypatch，不改生产源代码。共同保持输入、空初态、合成身份、模型 fixture、生成配置、披露模式和调用预算。D0/D1 的 Teacher/证明/练习提示在 harness 中替换为普通教学提示；D2 保留项目原生分支。D1 核验后绕过额外模型复核，避免把普通 LLM + 确定性工具组变成另一个完整 Agent。

提示长度、可用证据、结构化协议与原生辅助调用数是预定差异，不能宣称完全相同资源。课程检索是否命中、决策是否 accepted/fallback 按实际回执查看。空初态无法检验长期个性化；合成身份无法验收 JWT。

## 评分与公平性

复用 S5 的严格 JSON/摘要读取与 `policy_comparison.py`。`r5_quality.py` 检查材料漂移、固定分母、缺失/重复观察、逐题三组输入与初态一致性。比较工具在缺少可比真实评分时保留 baseline，不将工具消融误当同资源策略升级证据。

指标包括数学正确性、正确步骤误判、错误定位、条件意识、unknown、反馈针对性与证据一致性。报告保留计划、完成、失败、未评分和 N/A，真实模型指标保持 null。合成评分只用于测试聚合工具，不能进入真实模型成绩。

本轮 `offline-release` 采集完成 72 次，但只有 22/24 题满足三组干预控制。N03、Q03 的原生分支未进入受控生成阶段，单列不可比较。详见 [失败分析](failure-analysis.md)。采集脚本、辅助工具、案例与组别配置的摘要写入报告；复现时使用新输出名，保留已有记录。

此入口没有 live 传输，不能因为环境里有密钥就调用模型。真实模型接入还需独立审核、单独授权、供应商/模型白名单、token 上界、逐次发送前预留预算、请求/费用上限和失败持久化。
