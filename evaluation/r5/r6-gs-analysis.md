# R6 的 G03 修复与评测边界

## 冻结输入

继续使用 `cases-v1.json` 的 24 个公开开发题和 `arms-v1.json` 的 D0/D1/D2，不另建评测框架。[冻结清单](r6-freeze-v1.json)记录材料与采集脚本摘要。G03 保持原题，不改答案来配合新实现。

H01–H06 仍是空保留名额，题目和 rubric 均为 null。它们必须由独立作者撰写、审核并封存；本轮没有生成假 gold，也没有把公开开发题重命名为未见保留题。

## G03 的纵向改进

原问题是从“不满足严格行对角占优”跳到“GS 必定发散”。新探索复用该题中的矩阵：

```
A = [[1, 2], [0.1, 1]]
B_GS = [[0, -2], [0, 1/5]]
rho(B_GS) = 1/5 < 1
```

对于这个矩阵，严格行对角占优不是成立的条件，但 GS 迭代收敛。浮点轨迹仍标记为有限参考计算；二阶矩阵判据由有理数规则另行给出。学生必须写预测、确认参数并自行修订主张，系统不自动把他判为掌握。

Chat 引用运行时重新核对轨迹、任务、来源和帮助状态，并重新计算矩阵判据；保存记录中伪造的谱半径会被拒绝。对高于二阶的谱半径返回 unknown，不从若干次轨迹虚构定理结论。

## 本轮离线结果

命令：

```powershell
python scripts/eval_r5.py --offline --output results/r6/r5-offline.json
```

本机完成 72/72 次固定回复采集，失败 0；22/24 题满足三组干预条件。N03、Q03 仍按原[失败分析](failure-analysis.md)保留为不可公平比较，未删除分母。本轮没有将它们改成通过，也没有扩大真实模型预算。

原始逐次回执、来源摘要、调用数、耗时与拒绝联网记录见本机输出；固定回复的 token 与费用为 null，而不是伪造为已测量的零。真实模型调用数为 0，真实质量分数为 null。该结果证明离线编排仍可复现，不能证明新功能提高了真实模型正确率或学生学习效果。

本轮针对性回归见 `apps/api/tests/test_explorations.py`：G03精确谱半径、非收敛矩阵、高阶unknown、证据篡改拒绝、参数/权限/帮助锁与原子恢复。它验证受控核验规则，不评价模型自由回答。

## 仍缺的评测

真实模型消融需先完成保留题封存、数学审核和费用授权。真人试验还需独立任务、帮助记录、跨会话恢复失败、延迟迁移与退出率。EVAL-01 的冻结、离线消融、针对性修复及失败记录已落地；真人 gold、live 成本与学习收益仍未验证。
