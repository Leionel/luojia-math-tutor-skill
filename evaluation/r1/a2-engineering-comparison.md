**暂行决定**：D1 仅作为本题活动引用的工程路径。它复用已保存 Root Runner 与 `EXACT_CHECK`，不需要再次执行不可信表达式，也不把模型意见写成 `verified`、`is_correct`、mastery 或 mistake。证据不足时提示未知/追问；任何输出都不能把 x₀=0 的代入推广到任意初值。D0 是离线对照定义，不新增公开产品开关；D2 暂不实施。若未来经审案例显示 D1 误判正确步骤、遗漏前提或延迟不可接受，应重新选择路径，不守护这个暂行决定。

本轮固定模型测试只断言服务器原话进入 prompt、`exact_check` 附加范围、旧/跨 owner/错 hash/帮助锁拒绝和无学习写入。没有完成 16 题真实模型采样，也没有模型请求数、usage、费用或端到端延迟分布；对应分母均为 0 / 未运行。未来运行须先完成独立数学审核、同模型与同预算固定、真实 HTTP 前的 S5.3 供应商与费用准入。D2 若进入比较，还须记录无效 JSON、超时和降级，不把格式通过率当正确率。
