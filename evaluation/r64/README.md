## 三类实跑证据

模型计划来自明确标识的 fixture，执行使用原 runner；以下数学观察可以复算，不能算模型设计能力。浏览器中编辑共同 limit 后，预测、执行、主张修订和讨论引用均保存并恢复。

| 领域与主张 | 控制实验 / 工具 | 实际证据 | 修订及范围 |
|---|---|---|---|
| GS：不严格行对角占优就发散？ | 二阶矩阵 `[[4,1],[1,3]]` 与 `[[1,2],[.1,1]]`；固定 b、x0、方法与停止规则 | 后者不严格占优，按十进制有理数解释的误差矩阵谱半径为 1/5；残差第 10 步约 9.216e-7 | 充分条件未满足不能推出发散；谱半径结论针对这个矩阵，轨迹不是一般证明 |
| Newton：`x^3-2x+2` 任意初值都收敛？ | 固定函数与更新，比较 x0=0、-2 | 0→1→0 至步数上限；-2 第 4 步 x≈-1.76929235424，残差约 5.054e-13 | 保留正确第一步，撤回全称推广；不推断完整吸引域或严格根误差界 |
| 积分：小估计能保证严格误差界？ | Simpson 对 `sin(8*pi*x)^2` 在 [0,1]，初始 n=4、6，各细分一次 | n=4→8 近似约 3.199e-31、估计 0；n=6→12 近似 0.5、估计约 2.961e-17；严格界字段均 null | 光滑振荡函数网格混叠；解析积分 1/2，首组真实误差接近 1/2，估计不能自动升格为界 |

浏览器积分另用平滑多项式 x^4、n=4/8，观察近似改善后修订；混叠反例在 API 采集中执行。15 个开发槽位各覆盖局部正确、条件不足、错误全称、反例设计、工具不能判断。后四类没有真实模型行为评分；fixture 的 unknown 只验证解析与编排，不代表模型会正确拒绝。

## 私人上下文配对

每个领域各有相关、不相关、来源版本失效三个场景，共 9 对。P0/P1 使用同一持久化合成历史、问题、owner、课程、公共提示、模型和资源声明；只改变是否供给筛选后的私人上下文。不把上一组回答传给下一组。运行时关闭两组语义补充和目标检索，以排除时序差异；这也限制了对生产检索全路径的外推。

完整输入保存在每组 artifact。检查时只移除 `personal_context`、由其产生的 `personal:*` 来源索引和派生摘要，其余提示投影须相同。相同上限不等于相同实际 token，当前未调用模型，因此 usage 仍为 null。

| 场景 | P0 选取 | P1 选取 | 观察 |
|---|---:|---:|---|
| 相关，三个领域 | 各 0 | 各 1 | 原主张、修订、具体实验、ID/版本、私人权威与选择理由进入实际 Chat 输入并保存 |
| 不相关，三个领域 | 各 0 | 各 0 | 不混入其他领域旧关系 |
| 旧来源失效，三个领域 | 各 0 | 各 0 | 不把新版本静默替换成旧证据 |

两组回复故意使用同一中性固定文本，**没有模拟追问收益**。真实针对性差异、错误记忆污染率、置信范围均未评分。评分工具 `paired_review_summary` 保留逐对 P1−P0、退化值、未评分分母和混杂；仅接受签名字段、输入/回答/rubric 摘要和逐项原句依据，拒绝给 fixture 加真实分。小样本区间会很宽，公开开发题也不能支持总体推广。导入者提供的录音/回答不等于工具认证了真实执行。

人工审核需逐项给出原句与理由：结论；条件和量词；正确局部步骤是否保留；最早错误；实验相关性与可执行性；控制变量；unknown；证据越界；追问针对性；错误记忆污染；帮助泄露。未审核与不适用分别用 null 状态和理由，不合成综合分。

## 浏览器任务

5 项为：Chat 草稿进入 GS 并恢复；Newton 执行后讨论与返回；积分执行后讨论与返回；接受后的私人图重新加载；Newton 材料选段进入 Chat、保存回答、恢复原文引用。三类任务均检查真实保存预测、主张修订和计算记录；清除探索或阅读临时草稿后恢复，未把 localStorage 作为业务事实源。固定响应不评价教学质量。

脚本为 [领域流程](../../scripts/r64_ui_tasks.cjs) 和 [恢复流程](../../scripts/r64_ui_restore.cjs)。首个领域流程从已通过可见 Chat 链接进入、且主张为“GS不满足严格行对角占优是否一定发散？”的 Explore 页面启动；后两类由脚本通过可见入口自行进入。回执工具绑定 CLI 原始日志、截图和源码摘要；它记录自动化声明，不是独立见证或真人研究。
