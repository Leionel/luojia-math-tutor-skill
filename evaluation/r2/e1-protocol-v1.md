# R2.3｜E1 同题对照运行合同（尚未运行）

首轮开发题取 A0 的 N01（正确步骤）、N02（错误全称推广）、L01（正确 Jacobi）、L02（GS 更新顺序）、T01（正确但有限的讲回）、T04（信息不足）。这 6 题都已公开并参与开发；只用于发现失败类型，**不是封存确认集**。每题 D0/D1 各一条应用路径回答，计划观察单元为 6×2=12，实际分母目前为 **0**。若某领域无法在相同保存对象与相同用户输入上实现仅一项主要因素不同的两臂，就把该题标为“对照不成立”，不凑成12次比较。

固定输入：相同模型/版本、同一原话、owner、会话初态、已保存引用及其 hash、课程版本、帮助状态、温度和最大输出；每臂重置隔离数据库和会话，禁止把前一臂回答写回后一臂。D0 保留经服务器重读的原话与引用事实，但拿掉特定确定性数学证据；D1 只加对应领域实际可达的受控工具/条件证据，记录工具是否调用、参数、来源、失败和 unknown。不能把“更多上下文 + 更多工具 + 不同 prompt”合并后归功于工具。A2 已有 prompt 合同只证明 Newton 快照可作这种工程差分，不证明线性或讲回的应用路径对照现成可用。

每条记录至少保留脱敏 run ID、代码/模型/prompt/rubric 版本、输入和响应摘要、应用入口、路由/上下文/工具/最终答复阶段状态、请求数与重试数、token usage（未知写 unknown）、端到端延迟、失败原因。原始学生数据、密钥和服务端 URL 不写进公开结果。现有 S5 录制回答导入只认证格式和哈希，不能认证真实应用来源；R2.3 须另验证采集器的真实 ASGI/HTTP 路径后才能宣称应用对照。

人工逐题评分分开记录：数学结论、条件与量词、正确步骤误判、应当 unknown/追问、首错定位、帮助泄露、证据越界、教学动作合适性。每项注明适用性与证据位置；未评分为 `null`，不适用为 N/A，失败执行仍在计划分母内。B2/B3/B4 不用单选或静态规则命中冒充开放回答成绩。报告 D0/D1 的配对差异和失败案例，不把能力消融直接说成准确率提高；D2 只在经审失败簇显示结构化审阅有可能解决具体问题时另开试验。

**启动 Gate**：A0/S5 相关题有可追溯的真人作者审核与独立数学复核；真实供应商预检、预算和消费授权齐全；采集器能证明同一真实应用入口且无前臂状态泄漏。缺一项就只保留离线工程合同，不启动付费模型，不生成质量百分比。
