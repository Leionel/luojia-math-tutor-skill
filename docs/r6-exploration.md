## 使用流程

侧栏“学习工具与资料 → 数学探索”，或直接打开 `/explore`：

1. 写下主张并保存，创建探索。
2. 添加私人节点；可选择官方课程节点、自己的笔记或资料首章。连接两个节点，选择关系并写理由，保存。
3. 采用 GS 对照建议或手工填参，写预测，选择指标，确认后运行。
4. 查看每次计算的轨迹和矩阵判据，修订主张并写依据。
5. 从运行卡进入 Chat 讨论。返回探索后可继续关联会话；学习记录也可重新打开探索。
6. 过程记录可恢复任一版本的私人图。恢复不撤销主张与实验历史。当前完整探索、最近实验参数和预测可从服务端重新读取；未提交草稿仅保存在当前账号的浏览器中。

普通 Chat 继续支持纯对话，不要求创建探索或执行实验。

## 记录与失败处理

`gs-exploration-v1` 记录 owner、course、revision、原始主张、私人图、来源绑定、历史、计算引用与请求回执。主张标记为 `unreviewed_student_claim`，独立成功始终为 false。每个探索最多 20 个节点、30 条关系、100 次保存和 10 次计算。

来源绑定复用 ReadingContextRef，或使用课程节点 + graph_revision、笔记 ID + 内容哈希。读取历史时显示来源失效；保存绑定及运行前再次核对。删除、换版或越权不会自动换成另一份来源。

修改要求 expected_revision。相同请求 ID 和相同内容可安全重试；相同 ID 不同内容或并发旧版修改返回 409。探索与数值运行写在同一课程库事务中，存储失败一起回滚。浏览器保留未确认请求，刷新后可重试；不会自动重新运行。

Chat 仍通过已有 LinearContextRef 校验 owner、版本、数值轨迹与帮助状态，再重新计算矩阵判据。它不会信任历史 JSON 中自称正确的谱半径，也不把来源文字提升为系统指令。独立检验期间拒绝探索参考内容与运行，包含历史读取及重复请求。

## 数学范围

建议是确定性模板，不是模型生成或已执行的结论。二阶矩阵按输入浮点数显示出的十进制有理数解释，计算 GS 误差矩阵及精确谱半径。它不是对原始文件任意精度数字的无损符号解析。

G03 的矩阵 `[[1,2],[0.1,1]]` 不严格行对角占优，但其 GS 谱半径为 `1/5`。它反驳“非严格行对角占优一定发散”，不支持“所有这类矩阵都收敛”。对于高于二阶的输入，当前谱半径证据返回 unknown，仍可在预算内查看浮点轨迹。

有限残差轨迹、特定矩阵判据、学生主张审核和独立掌握是四种不同证据。当前没有任意自然语言证明判分、自动关系审核或学习收益结论。

## 教师账户开通

公开注册会拒绝 `TEACHER_USER_IDS` 中的保留名，不影响已经存在的教师账号登录。新教师可先以普通账号注册，由管理员线下核验账号归属后再加入服务端教师名单；不能让注册请求自行声明角色。名单中尚未建号的保留名称应通过可信管理操作创建。本轮没有修改现有账号、密码或部署名单。

管理员还需核验历史教师同名账号的真实归属；本轮没有读取正式账号库，无法判断旧注册是否已经被利用。
