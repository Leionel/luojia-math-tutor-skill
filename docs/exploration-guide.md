# 完成一次数学探索

从自由对话输入一个想检查的判断，例如“矩阵不满足严格行对角占优，GS 就一定发散吗？”可以先发送并保存会话，再点击输入框旁的 **围绕当前问题探索**。未发送的文字也能转交。

1. **保存主张。** 检查转交的文字，填写探索名称，点击“保存并开始探索”。页面上方会提示下一步。
2. **选择实验。** 可以请助教建议，也可以点击“手工设计实验（无需模型）”。没有模型服务时，可用明确标注的 GS 默认示例。默认示例不代表已验证你的主张。
3. **先预测，再确认计算。** 采用建议只会填入可编辑参数。核对两组改变和保持的因素，写下运行前预测，再勾选确认并执行。计算结果会保存。
4. **比较并修订。** 看清本次计算的适用范围，在主张处填写修订理由并保存。原判断、预测与旧计算仍在历史中。
5. **回到讨论。** 每组结果下方可以带着这次计算进入对话。页面上方的“返回原会话”可继续原讨论；从独立探索开始时显示“返回自由对话”。

GS、Newton 和数值积分使用同一流程，但参数与观察量不同。GS 的有限轨迹不能证明所有矩阵的结论；Newton 的残差达标不等于严格根误差界；积分误差估计也不等于严格误差上界。

## 回看来源和历史

- **私人图：** 在“我的知识网络”选择探索，顶部直接返回这次探索与历史，无需先点节点。课程图与私人图有独立入口。
- **学习记录：** 点击记录的来源链接，再用“选择探索历史版本”查看当时的主张、预测和修订理由。历史只读；下方编辑表单始终属于最新版本。
- **资料：** 从“我的资料”选择一份已有解析原文的材料，再选择章节进入对话。发送后的回答保留实际引用的原文，可刷新后展开查看。
- **聊天：** “回看原始来源”保留探索版本及计算定位。找不到指定历史版本时会明确提示，不会自动换成另一个历史版本。

## 看懂证据标记

| 标记 | 含义 |
|---|---|
| 课程来源 | 沿用原有审核状态，课程收录不等于所有内容都已独立数学审校 |
| 私人关系 | 学生接受或编辑的意见，不会自动成为课程图的正式知识 |
| 模型建议 | 需要核对的提议；采用参数还没有执行实验 |
| 受控计算 | 针对指定输入的计算证据，不代表一般证明或学生已掌握 |

## 等待或失败时

模型建议不会自动重试。网络中断后，先使用“重新读取已保存建议（不调用模型）”，确认服务端是否已经保存，避免重复请求。没有可用建议时，参数草稿仍可继续编辑，也可以使用无需模型的路径。

提交结果尚未确认时，保留文字并核对已保存版本，再重试同一提交。出现版本冲突时先对照历史，不要直接覆盖另一处更新。浏览器草稿只是方便续写；已保存的主张、预测、计算和修订来自服务端。

来源或会话正在恢复时，输入框暂时只读，完成后会开放；这能避免刚输入的问题被初始化清空。回答生成期间仍可写下一问的草稿。
