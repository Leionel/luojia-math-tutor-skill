# 已知限制与安全边界

## 数学判断

- 步骤检查只支持有限语法和局部候选，无法判断任意多步证明。未覆盖、条件不完整或超出计算预算时应返回 unknown。
- 确定性结果只对标注范围与当前输入成立；模型对整个证明的意见仍可能错误。课程文本也可能存在遗漏或录入错误。
- 交付检查能识别部分明确冲突、泄露和核验越界，尚不能覆盖所有改写、英语判词或隐含数学结论。
- 旧核验记录保留版本与来源；修复核验器不会自动重算历史学生记录。需要时应显式重新检查，不能追溯改写学习历史。

## 教学与个性化

- 教学决策 schema 合法不等于诊断正确；提示层级、BKT 参数及错误策略缺少真实学生校准。
- Newton 等已有保存、讨论与对照路径，但不同领域的教学深度不一致。代码工坊的限定静态诊断不能代表任意程序执行或完整自动评分。
- 学习总结服务尚缺完整的学生入口与跨会话体验；移动端、键盘、恢复和身份切换仍需系统任务验收。
- 当前没有足够独立数学 gold、真实模型对照和学习收益数据。工程回归通过不产生这些结论。

## 来源与课程图

`verified` 是课程发布状态。应进一步核对原教材、适用条件、版权与审核者记录。检索和图关系辅助定位证据，不能保证召回完整或自动证明定理。

## 安全与部署

模型输出、上传文件名、表达式和交互参数均按不可信输入处理。沿用有限表达式解析、HTML 清洗、服务端 owner/版本/帮助校验；新增输入路径仍需检查是否绕过这些边界。

本地 `.env.example` 默认用于开发。生产需要显式鉴权密钥、合法 Web 来源、数据隔离及上传策略。正式数据库备份恢复、迁移、目标环境授权正反例与运维监控尚需部署方验收。本轮只在隔离数据和离线测试中验证，不修改正式数据库或部署配置。

外部模型、文档解析、语义服务和嵌入式可视化有各自的可用性、隐私与费用边界；默认离线评测不验证这些服务。


## R6.1 数学探索建议

GS/Newton 参数可以编辑并由受控运行器执行。经授权的6次真实模型小样本尚未通过实验建议能力验收：首批截断，第二批出现GS仅澄清、Newton动作/候选图契约不一致、把未知比较量猜成残差的问题。修复后的提示仍需重新做真实验收；当前不能声称两类数学问题均可可靠交付Agent实验建议。详见[执行报告](../evaluation/r61-execution-report.md)。
