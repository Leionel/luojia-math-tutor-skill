# R5 数值研习册：交互原型

独立 HTML/CSS/JavaScript，无新依赖、模型调用或正式数据库访问。可直接双击 `index.html`，推荐使用本地 HTTP 预览以便保存状态和验收。

## 运行

在仓库根目录执行：

```powershell
python -m http.server 3185 --bind 127.0.0.1 --directory design/prototypes/r5
```

## 试一条完整路径

1. 从学习中心开始 Newton 任务；读条件后写预测。
2. 观察 `1→0→1`。可以故意选择错误的全称结论，查看明确标记的规则反馈。
3. 以 `−2` 为初值对照，写下修订，再进入新题的独立数值检验。
4. 先试一个错误候选，再修改；或者查看参考帮助。帮助标签会保留，刷新不会变回独立完成。
5. 打开学习记录，回到这次运行；在实验中心切换 A/B 布局，选步骤讨论。

也可以从记录中的“残差很小，就一定离根很近吗？”进入复习。先看原反例，再对 `g(x)=10⁻⁸(x−2)` 的新题作答；原错误、参考依据与新尝试分别保留。数值匹配不表示文字理由已被核验。

GS 示例输入 `4 1; 2 3`、`1 2`、`0 0`。第一轮为 `[0.25, 0.5]`。积分示例固定 `exp(x)`，可以改变区间、规则和子区间数；奇数段 Simpson 会明确拒绝，输入保留。

移动端主导航位于底部，讨论面板按阅读顺序排列；所有输入有标签，可用 Tab/Shift+Tab 和 Enter 操作，讨论抽屉用 Escape 关闭。原型设置可体验空记录或重置本原型的数据。

## A/B 的取舍

- **普通对话是一级入口**：默认没有材料或实验面板，不要求进入学习任务。首页可直接带着问题开始，也可选择一份材料来聊。
- **材料伴读按需展开**：支持 UTF-8 `.txt` / `.md` 或粘贴正文（200KB、20000 字符以内），选择整段或鼠标选中文字后提问。消息保存当时的材料版本和原文选段；换材料或移除引用不会重写旧消息。原型不解析 PDF，正式集成应复用既有 Reading 解析与规范引用。
- **B 为实验中心默认建议**：主要动作是修改参数、选步骤、看对照，助教跟随当前来源。
- **A 保留为对话模式**：适合较长推理与追问；实验承担引用证据，不抢占主要阅读区。
- **学习任务页保持独立的进程布局**：它承担阶段、判断与帮助状态，不能简单替换成 A 或 B。

两种模式切换同一状态，不形成两套后端能力。正式产品是否采用，等待用户预览和选择。

## 数据与计算范围

Logo 与小珞来自现有公开品牌素材。示例阅读内容是教学说明，不是教材原文；seed 记录明确为演示。计算使用有界浏览器浮点算法，快照摘要仅是原型标识，不替代正式 owner/hash/version 回执。

本原型不会读取登录信息或访问 API。仅写 `luojia-r5-prototype-v1` 这个 localStorage 项。小珞的预写规则示例不表示真实模型表现，独立题只核对一次固定数值更新，不评价学习收益。

普通消息仅保存在原型会话中，不生成模型回答。“纯对话示例”和“材料伴读示例”均明确标为预写。材料示例为原型编写的讲义，非教材原文；用户导入的文本保持原样，未经来源或数学审核。

现状、功能分工和路径对照见 [review.md](review.md)，实际走查、验证结果和建议见 [acceptance.md](acceptance.md)。算法回归：
