# R3 补充规划｜学习工作区视觉重塑与统一设计规范 (UI/UX Specification)

> **关联基线与依据**：本文件是 [r3-agent-capabilities-2026-10-14.md](r3-agent-capabilities-2026-10-14.md) §3A（Intelligent UI 与 Chat/工作区统一）的**专项设计与实施规划补充文档**。针对 2026-10-14 用户反馈“现在的太简单、太一般；要求先不直接改代码，系统性规划，形成统一而美观的补充方案”，本文件明确六大工作区（Study、Reading、Lab、Assessment、Teach-back、Code Workshop）的视觉统一系统、组件标准与实施细化。**本轮为规划文档建立，不直接改动业务代码，不增加模型消费。**

## 1. 现状痛点与重塑目标

### 1.1 现状诊断：“太一般”的根源
1. **容器缺乏质感（表单孤岛）**：现有页面大面积使用基础的 `bg-white border rounded-xl` 简单卡片包裹，缺乏材质层次、呼吸留白与数理研学氛围，呈现为廉价的“信息录入表单”。
2. **布局空间割裂（缺乏空间记忆）**：各页面左右栏比例不一（如有的 260px+1fr，有的单列），按钮形态、内边距、状态标识各自为政，切页体验割裂。
3. **输入控件极其简陋**：大段使用浏览器原生未修饰的 `<textarea>`、`<select>` 与单选圆点；尤其在代码工坊中，使用原生文本域书写 Python，缺失语法高亮、行号槽与诊断标记。
4. **与 R3 Agent 能力脱节**：R3 规划中的 `PredictionForm`（预测先行）、`ParameterCompare`（单变量受控对照）、`ConditionChecklist`（定理条件清单）与 `CodeLineFeedback`（行级反馈）缺乏成体系的高质感视觉载体。

### 1.2 重塑目标
* **视觉美学升阶**：确立**【现代书院水墨研学工坊（Scholarly Atelier）】**专属设计语言，融合东方纸墨温润意境与现代高数严谨度，彻底告别普通 AI 产品的紫蓝渐变或冰冷工具感。
* **全局高度统一**：确立全站一致的“三栏黄金推演舞台”布局、统一的印章徽标系统、统一的助教思辨气泡与数学级输入控件。
* **业务逻辑无缝继承**：保持当前 FastAPI 后端 API、`learning-api.ts`、`localStorage` 暂存机制与权限安全门禁 100% 兼容，仅做表现层与交互形态的升阶。

### 2.2 字体排印与版面节奏（Typography & Hierarchy）
* **大标题与篇章题头**：使用 **站酷小薇体（`font-title: ZCOOL XiaoWei`）**，字重清秀挺拔，具有东方宋代刻本的古风骨骼。
* **研学正文与说明**：使用 `font-sans: Noto Sans SC`，字距稍显舒展（`tracking-wide`），行高统一为 `leading-relaxed`。
* **数学公式排版**：使用 `KaTeX` 深度渲染，行间公式统一具有典雅微缩进与左右呼吸留白；关键变量以黛蓝或橄榄绿微光下划线标注。
* **算法代码与数值轨迹**：统一使用 **`JetBrains Mono`**，具有清晰的字符区分度与严密的等宽网格。

## 3. 全局空间架构：三栏黄金推演舞台（Unified Layout Architecture）

六个工作区全部归一化到统一的响应式三栏空间架构，形成高度稳定的用户空间记忆：

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│  顶部研学状态缎带 (Atelier Ribbon)                                                      │
│  [章节标识: 非线性方程求根] · [当前课题: 牛顿法收敛性] · [状态胶囊: 推演中] · [对话助教 ↗]    │
├───────────────────┬────────────────────────────────────────────┬───────────────────────┤
│  左栏：知识脉络导航 │  中栏：核心演算与研学主舞台                  │  右栏：定理条件与助教  │
│  (Nav & Context)  │  (Cognitive Workspace Stage)               │  (Socratic Companion) │
│  固定 260px       │  自适应弹性 minmax(0, 1fr)                  │  固定 320px (可折叠)   │
├───────────────────┼────────────────────────────────────────────┼───────────────────────┤
│ • 章节与单元导引  │ • Reading: 双栏学者批注古籍正文与公式      │ • 定理必备条件清单    │
│ • Study: 日课航标 │ • Lab: 动态切线几何画布 ＋ 交互控制板       │ • 助教思辨质疑气泡    │
│ • Code: 提交版本树│ • Code: 水墨 IDE 编辑器 ＋ 双版本 Diff     │ • 划选反例与证据溯源  │
│ • Teach: 讲学历史 │ • Teach-back: 大字富文本讲学幕布           │ • 行级诊断详情卡      │
│ • Assess: 维度图谱│ • Assessment: 试金石卡牌推演流             │ • 知识图谱薄弱点雷达  │
└───────────────────┴────────────────────────────────────────────┴───────────────────────┘
```

* **大屏端 (≥1280px)**：三栏并排，左栏负责回溯与选单，中栏为沉浸式推演舞台，右栏常驻显示助教思辨与定理条件。
* **中屏端 (768px–1279px)**：右栏折叠为可展开的右侧滑层或单层抽屉（保留键盘焦点，遵守 `rule/keyboard-complete-flow`）。
* **移动端 (≤767px)**：采用“主舞台 ＋ 对话/条件切换 Tab”，轻点浮标即可在演算舞台与助教抽屉间平滑呼应。

## 4. 六大工作区逐一升阶重塑规范

### 4.1 今日学习 (`/study`)：从“任务打卡”到“研学日课流与思维罗盘”
* **中栏主舞台（演算草稿台）**：
  * **今日挑战卡（Challenge Folio）**：以古籍书页形态呈现目标方程 $f(x)=0$、初值与收敛目标；
  * **交互式轨迹输入本（Interactive Trace Scratchpad）**：摒弃多行普通文本域，输入数值序列后自动转化为收敛芯片链（Step Chips），即时计算步长比 $\frac{\|x_{k+1}-x_k\|}{\|x_k-x_{k-1}\|}$ 并绘制微型残差折线图；
  * **停止依据选择卡**：以图文卡片取代下拉选择框，直观呈现“残差达标”、“相邻步长达标”与“到达上限”。
* **左栏（日课三阶航标）**：清晰划分“① 温故旧疑 ➔ ② 核心探索 ➔ ③ 独立验算”，以印章徽标标注完成状态。
* **右栏（助教导学与复盘建议）**：展示基于历史错题的建议卡（`LearningRecommendation`），支持一键激活跨页探讨。

### 4.2 教材伴读 (`/reading`)：从“文本堆砌”到“学者批注桌（Scholarly Marginalia）”
* **中栏主舞台（典籍正文）**：
  * 仿照 Tufte 经典排版与古代刻本朱墨套印：正文大字优雅排版，关键定理以双线框与印章微标加冕；
  * **划选即问微气泡（Highlight-to-Probe Bubble）**：学生划选任意段落或公式，浮现水墨微光操作气泡：`[查看先决条件]`、`[索取发散反例]`、`[发往实验台验证]`。
* **左栏（文献大纲与知识树）**：支持在预置课程摘录与学生自上传教材文档（MinerU PDF 结构化结果）之间无缝切换，显示段落字符跨度校验。
* **右栏（边注 Marginalia 与条件核对柱）**：
  * 与正文段落精确垂直对齐的边注，展示该公式对应的**适用条件清单（Condition Checklist）**；
  * 下方常驻随堂思考问答卡与思考笔记（`ReadingNote`）锚定列表。

### 4.3 数值实验 (`/lab`)：从“参数输入框”到“探究式数值推演工坊”
* **中栏主舞台（动态几何演播室 ＋ 实验仪器台）**：
  * **几何切线画布（Dynamic Tangent Canvas）**：支持逐帧单步推进（Step-by-step Scrubbing），动态绘制从 $(x_k, f(x_k))$ 沿切线投影至横轴 $(x_{k+1}, 0)$ 的动画；
  * **微调刻度控制板（Precision Control HUD）**：高质感滑块与微调步进器，初值变动实时反馈到坐标轴上的微光定位标；
  * **双轨迹对比视窗（A/B Comparison View）**：并列展示基准实验（Run A）与变因对照实验（Run B）的收敛速度与相位图。
* **左栏（实验题库与历史谱系）**：分类展示经典收敛、循环震荡、越界发散等预设案题及当前会话的探索分支。
* **右栏（受控单变量实验台）**：
  * 严格落实 R3.2 规范：Agent 提出实验建议时，锁定其余变量，仅高亮一个待测参数（`changed_parameter`）；
  * **预测先行卡（PredictionForm）**：在真实 Run 计算前，引导学生先行记录对收敛趋势的预判。

### 4.4 章节自检 (`/assessment`)：从“单选题表单”到“三阶试金石与认知漏洞雷达”
* **中栏主舞台（试金石卡牌推演流）**：
  * 告别试卷感，以卡牌流聚焦当前题目，明确标注考查维度（【条件判定】、【单步迭代】、【停止准则陷阱】）；
  * **水墨单选卡**：选项采用卡片式微悬浮，选中呈现橄榄绿印章边框；
  * **三层剥茧式反馈（Three-Tier Feedback）**：交卷后按 R3.4 阶梯展开：
    1. *第一层 · 条件探针*（引导重审前提是否缺失）；
    2. *第二层 · 方法支架*（启发式思维路径）；
    3. *第三层 · 完整参考题解与反思*。
* **左栏（维度进度树）**：雷达刻度盘实时呈现 6 道题目的维度覆盖度。
* **右栏（认知漏洞诊断书）**：针对错题，精准高亮知识图谱上的断裂节点，并附带直达 `/reading` 章节或 `/lab` 靶向验证的传送门。

### 4.5 讲给助教听 (`/teach-back`)：从“原句填报”到“苏格拉底讲学台与原句引线”
* **中栏主舞台（讲学大幕布）**：
  * 提供宽广、沉浸的富文本讲学书写区，鼓励学生用自己的自然语言讲授牛顿法原理、适用边界与停止依据；
  * **原句引线交互（Evidence Threading）**：学生在正文中选中某句话，右侧对应的定理条件卡片自动共鸣高亮，一键完成“原句 ↔ 条件”的视觉绑定，彻底摒弃繁琐的复制粘贴。
* **左栏（讲学版本库）**：记录历史讲授版本与补充答辩链（Parent/Child Revisions）。
* **右栏（定理条件锚点柱 ＋ 助教追问探针）**：
  * 竖向排列定理必备条件（$f'(x)\neq 0$、初值局部邻域、二阶导数有界）；
  * **小珞助教思辨探针（Socratic Probe）**：根据学生的讲学疏漏，生成带有启发意义的追问气泡（如“你提到了导数不能为零，那如果在迭代区间内出现拐点，收敛性会受到什么影响？”）。

### 4.6 代码工坊 (`/code-workshop`)：从“原生文本域”到“算法工匠 IDE 与版本辩论室”
* **中栏主舞台（水墨算法工匠 IDE）**：
  * **现代代码编辑器**：支持 Python 语法高亮（以纸墨/松柏/黛蓝为着色方案）、行号槽（Gutter）、自动缩进与当前行微光；
  * **行级诊断浮标（CodeLineFeedback）**：静态分析发现逻辑缺失（如缺少除零防范、只有残差而无上限步数）时，在对应行号旁浮现微光印章，点击可直接与助教展开代码级讨论；
  * **双版本 Diff 对比**：保存修订后，支持一键切换“双栏 Diff”，清晰观察本次修改行与静态提示减少项。
* **左栏（作业规范与提交版本谱系）**：常驻显示作业函数签名、数学目标区间与历史提交版本列表。
* **右栏（手动轨迹诊断雷达）**：并列对比前后两次提交所附带的数值轨迹，展示残差下降斜率的变化曲线。

## 6. 实施原则与落地边界（Implementation Principles）

1. **零逻辑侵入原则**：
   - 现有的 `learningRequest` 数据接口、`localStorage` 私题与草稿暂存规则、`stableRequestId` 幂等签名保持完全不动；
   - 保证离线自动化测试套件（`npm test`、API 后端测试、Web 端 typecheck 与 lint）在整个 UI 改造期间始终保持绿灯通过。
2. **渐进式实施次序（与 R3 规划切片严格对应）**：
   - **UI-a 切片（3–5日）**：先落地通用样式构件（`AtelierFolioCard`、`SocraticBubble`）并在 `/lab` 落地动态切线控制与单变量对照（配合 R3.1/R3.2 闭环）；
   - **UI-b 切片（2–3日）**：推进 `/reading` 与 `/study` 的学者批注排版、条件清单与草稿芯片流；
   - **UI-c 切片（2–3日）**：推进 `/code-workshop` 水墨编辑器与 `/teach-back` 原句引线交互。
3. **性能与无障碍保障**：
   - 严格遵循 `rule/inline-before-modal`、`rule/preserve-user-input` 与 `rule/keyboard-complete-flow`；
   - 保证移动端（约 390px 视口）与桌面端均具备单手或键盘全流程可操作性，切换视图或重试时不丢失输入草稿。

## 7. 规划自检与签署

* **完整性**：覆盖 study、reading、lab、assessment、teach-back、code-workshop 全部 6 个页面的空间排布、视觉意境与交互规范。
* **一致性**：严格契合 `planning/r3-agent-capabilities-2026-10-14.md` 中的切片时间表、UI-a/b/c 增量边界及农场水墨设计体系。
* **执行约束**：明确当前仅作为规划设计文档储备，不直接改写生产代码，后续按切片任务单项推进。
