## B1 F1：基于保存状态的下一步

复用今日学习记录、任务状态、复习日期、课程版本和现有 Chat 只读任务入口，按固定优先级显示一项建议及原因。自检未交卷优先回自检；随后是待确认反馈/需修订过程、到期复习、失效课程来源、可续接任务；无可信状态时回到人工选任务。只读，不更改掌握度或计划。直达路径受前端白名单和服务端 owner/版本检查约束。旧记录缺字段时 Chat 使用中性建议，不伪造可用任务。

本地 UI 在隔离账号无任务状态下显示中性建议和“在下方选择”入口。规则合同覆盖不同任务/日期/版本与跨 owner，未测真实学生是否觉得推荐合适。

## B2 F2：开发条件卡的题目对照

在课程摘录的选段讨论里，学生可输入本题原话，标记自己认为已给出的条件。前端固定原文字符范围、source hash、graph revision 与条件卡 hash；服务端重新解析当前课程卡。Chat 上下文保留题目原话和每项“学生自报已给出但未核验 / 尚不确定”状态，只提出一个需指出依据的追问。勾选不是自动证明，未勾选也不等于条件为假。上传原文没有课程条件卡，不允许借用；旧卡版本拒绝恢复。没有新增图谱节点、模型评分或掌握度写入。

本地 UI 在 `NA_NEWTON` 开发卡上输入题目、勾选一项、打开同页 Chat、回到选段后，题目与勾选状态恢复，卡片仍标“开发条件卡 / 尚未经数学核验”。回链只带课程来源与页面锚点，题目全文留在该账号当前浏览器的本地恢复记录中；跨浏览器无记录时只返回来源，不伪造状态。这个切片只提供可追问的开发态输入与证据绑定；**不会从自由题干自动推导前提或判定定理适用**。正式 B2 内容 Gate 仍需条件卡与来源的独立审核；真实模型追问的数学准确性和教学价值也需另测。
