## 已实现的产品路径

在 `/lab` 运行参考实验，拖动到某一步后点击“问小珞：解释第 k 步”，桌面侧栏或手机抽屉读取当前实验。聊天与实验不用来回复制参数；也可以打开 `/chat?lab=<id>&step=<k>`，刷新恢复会话和引用。小珞的头像、中文衬线标题、橄榄绿与米白、留白和清楚的来源区沿用现有品牌。

通过交付检查并成功保存的回答带一张参数卡。卡片沿用原函数、方法与目标，用户可修改初值、阈值和迭代上限，点击预览后看到真实结果。参数再改动时旧预览不可保存；补充观察并点击“保存这次实验”才产生正式实验记录，同页更新结果与轨迹。观察明确标为“预览后的观察”，不冒充事前预测。

卡片来自服务器的固定业务映射，初始值沿用实验参数。**没有实现模型自主选择工具或自动填写推荐参数**。文字解释由模型生成，计算由既有受控 `root_runner` 完成；本路径关闭生成 Python 执行和联网搜索。原线性方程组、积分、二分法与不动点页面功能保留，尚未接入本批可信聊天合同。

## 数据与执行边界

- 客户端仅提交 `LearningContextRef`：类型、记录 ID、input_hash、runner_version、graph_revision 和有限 selected_step。服务端读取 owner 的保存记录，拒绝缺失、其他用户、篡改或过期版本；不能提交自造轨迹或 owner。
- 快照最多 11 行、8 KiB；保留首尾与所选步骤邻域。历史预算缺失时标为 `legacy_default`，没有编造原上限。聊天历史与教材摘录分别有字符上限；这不是全局 token / usage / 成本引擎。
- 引用是 `reference_help`，不进入学生作答、符号核验、mistake、BKT、mastery 或独立成功计数。引用读取无学习写入。发送、公开回答片段、最终交付与动作执行重验自检 / probe 帮助边界。
- 操作绑定成功且可见的 owner/session/message/run/artifact。服务器重读已保存卡片，Guard 未通过、未提交、失败、删除或截断后的消息不能授权操作；卡片 24 小时过期。
- 每卡最多三次不同预览、每次最多 100 次迭代。预览复用 owner-scoped 请求 ID，记录最小 `hint_exposed` 事件；即使不保存，该函数也从未见 probe 候选中排除。帮助预算是本卡预算，未宣称全课程全局预算或跨数据库 exactly-once。
- 保存复用 `LearningWorkspace.lab` 与确定性 request_id，只保存最新预览。重复保存相同观察返回同一记录，篡改哈希、旧预览、混用其他卡片或改变同一请求内容被拒绝。预览与正式结果的轨迹须一致。
- 两个聊天入口复用 `ChatLifetime` 与 `MathMessage`；笔记和实验另共享完整 `useTutorConversation` / `TutorConversation`。主聊天保留全页专有的会话、笔记与作答操作。锁在首次异步创建会话前取得，切换、卸载与退出使旧回调失效。取消只同步自身回执，失败 / EOF 不展示可执行卡片；草稿和会话映射按 owner 保存。

无新依赖、数据库表或 schema migration；新字段保存在已有 JSON 记录。既有 schema 6 的部署备份要求仍有效。已打开材料、旧历史与外部帮助不能收回；不将入口保护描述为考试防作弊系统。
