## 浏览器暂存的最后口径与本轮修正

独立复核发现：B5 已把私题从 Chat URL 移出，但教材自填题目仍经 `ReadingDiscussion` 保存到 `localStorage`，`referenceChatKey` 还把题目原话拼入本地存储键，内嵌讨论草稿也用同一键存于 `localStorage`。因此先前“URL 不含题目”成立，“本机不会长期留私题”不成立。`apps/web/lib/demo-auth.test.ts` 还曾把退出后保留未提交笔记作为显式合同。问题是同源浏览器中私题与草稿的留存范围，不是服务端跨账号授权绕过；没有复现其他用户通过 API 读取这些内容。

本轮按以下边界处理：

| 数据 | 最终行为 | 代价与边界 |
|---|---|---|
| 未发送的教材自填题目、该引用的讨论映射与草稿 | 改为同标签页 `sessionStorage`；同页刷新/Chat 续接可恢复，关闭标签页或退出登录后不再保证恢复。旧版 `localStorage` 私题尽可能迁入当前账号的本标签页，再删除持久副本；其他账号与损坏的旧项删除。 | 这是缩短本机留存时间，不是加密或 XSS 防护。浏览器“恢复上次会话”、复制标签页等行为仍受浏览器实现影响。 |
| 其他工作区未提交草稿、请求指纹与临时引用 | 保留现有“此设备刷新续写”体验；**确认退出、切换账号或其他标签页身份变化时清除** R1 相关本地草稿/指纹和用户自填模型 API Key，主题与模型名称等非密钥偏好保留。服务端已保存的笔记、实验、代码、讲回和消息不删除。 | 关闭标签页而未退出时，部分普通草稿和用户自填 Key 仍在 `localStorage`；这项可用性取舍不能称为全站敏感数据已脱离浏览器持久存储。清理旧键会使退出前未提交文字无法恢复。 |
| 发出后的 Chat 消息与可信引用 | 按账号由现有服务端会话持久化，读取时继续核对 owner、来源和版本。 | 清理浏览器草稿不等于删除服务器会话；若需要彻底删除，应走已有数据删除/保留策略，不能用本地清理冒充。 |

这一选择依据 [OWASP HTML5 Security Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/HTML5_Security_Cheat_Sheet.html) 对敏感数据不宜长期置于 `localStorage`、同源脚本可读的提醒，以及 [OWASP Session Management Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html) 对退出和不必要持久留存的建议。[MDN `sessionStorage`](https://developer.mozilla.org/en-US/docs/Web/API/Window/sessionStorage) 说明其按来源与标签页分隔、通常可在刷新后继续、标签页会话结束后清除；它依然可被同源脚本读取，不能替代输入/输出安全与服务端授权。本仓库现有认证令牌仍在 `localStorage`（`apps/web/lib/demo-auth.ts`），是 R0/认证架构的独立剩余风险；本轮没有把它误写成已解决。B5 之前已经访问的带私题 URL 和可能产生的历史/日志也无法由此追溯清除。

源码落点：`apps/web/lib/learning-browser-storage.ts` 负责旧私题迁移、学习草稿及用户自填模型 Key 清理；`ReadingDiscussion`、`ReferenceTutor`、`TutorConversation`、`TutorChat` 分别改用私题临时存储；`demo-auth.ts` 与 `AuthBoundary` 清理本标签页及可观察到的跨标签页身份变化。清理不触碰浏览器主题、模型名称偏好、服务器保存记录或数据库。

## 分 Gate 验收与停止条件

| Gate | 本轮口径 | 下一步取得什么证据才可改变状态 |
|---|---|---|
| R1-A 工程 | A0–A5 本地完成；Newton 已揭示切线、防剧透的内置入口范围、Chat↔Lab、线性复算和 Teach-back 条件续接按已有回执验收。本轮本地存储修正不改变数学工具。 | 若新回归发现 owner/版本/帮助锁跨越，立即重开相应切片。 |
| R1-B 工程 | B1–B5 本地完成；F1/F2/F4/F8 为开发参考能力。B5 浏览器曾实测今日任务、教材与自由 Newton；B3/B4 全点击链本轮未重演。 | 真实应用构建和离线回归应保持绿色；若私题仍出现在 URL/持久键或退出后草稿串号，重开 B2/B5。 |
| R1-A 数学/教学质量 | **未通过**。A0 案例与开放解释需非作者真人二审，应用实际路径需同题 D0/D1（D2 可选）对照；按正确步骤误判、条件遗漏、恰当 unknown、帮助越界、成本/延迟分别报告。 | 审阅者、逐题判据、固定输入/输出和原始回执均可追溯；缺任何一项不宣称质量提高。 |
| R1-B 内容/质量 | **未通过**。B2 条件卡与教材使用范围、B3 六题答案/rubric/分层文案、B4 正确与错误代码变体及误导审查待真人签署；B1 推荐适切性与跨工作区体验也未被学生试验证实。 | 签名或可追溯审核记录、反例修订和版本/旧卷处理完成后逐项放行；不能以 AI 二审代真人。 |
| R0 / 上线 | **未通过**。正式库备份/恢复、migration 与授权正负例仍依 v4 Gate 独立验收。 | 在目标 SHA 与正式流程验收前不部署或声称生产可用。 |

从本回执开始，R1-A/B **停止追加新能力**；只接受能复现的 P1/P2 回归、安全/数据隔离修复，或针对质量 Gate 所需的有界评测/内容修订。F2 PDF 精确页区域、F8 代码执行沙箱、长期 Memory/Reasoning Graph、新 Math IR/ProofState、Lean、A8 均保持条件延期。若 D2 只改善字段格式、不改善经审数学/教学判据，删除额外调用方案；若当前 D1 在未知情形持续给确定判断，先修降级与提示，不扩 Agent 层。
