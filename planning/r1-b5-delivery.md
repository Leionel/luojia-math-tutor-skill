## 本轮跨工作区验证

新增 `tests/test_r1_b5_workspaces.py`：在同一 owner、同一 Chat 会话里，先只读当前任务，再分别以教材选段、Newton 保存实验、线性保存实验和 Newton 代码保存版本进入同一个 `/api/tutor/context` 与 `/api/tutor/stream` 路径。每次都从服务端重新读取引用，检查原 ref 留在消息回执、参考帮助不变成独立作答/掌握度；换 code hash、线性 source hash 或换 owner 的私有引用会拒绝。另一条流程在自检进行中检查只允许返回作答入口、参考帮助被锁；六题交卷后原分数幂等保留，回到复习单元的教材来源，再进入 Chat。前端回归检查线性与代码引用回链到保存对象，代码原文不进 URL，缓存会话按 owner/code hash 隔离。

自检目前**没有单题答案直连 Chat 的可信引用合同**。交卷后的连续路径是“自检 → 复习单元 → 教材摘录 → Chat”，最后引用的是教材来源，不是学生该题的作答。B5 记录这个产品缺口，不借用 reading ref 冒充自检答案，也不在总验收时宣称该能力存在。

既有 [A4/A5](r1-a4-a5-delivery.md)、[B1/B2](r1-b1-b2-delivery.md) 与 [B3/B4](r1-b3-b4-delivery.md) 的隔离网页流程仍是对应 UI 证据；本轮同会话 ASGI/SSE 回归补跨工作区关系，不把以前各页点击次数相加为新的用户实验。
