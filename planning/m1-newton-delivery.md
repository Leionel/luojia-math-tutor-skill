# M1 Prompt B：Newton 参与式活动与实验台界面

2026-10-08，本轮在既有 `/lab` 实现单题活动：学生先保存预测与可选理由，再由 Root Runner 生成 `f(x)=x^3-2x+2, x₀=0` 的参考轨迹，随后保存解释和修订。原文与修订分别留存；刷新可恢复，重复请求用 requestId 幂等处理。可跳过预测直接看答案；帮助曝光、计算轨迹与学生文字不写成独立完成或掌握度。精确核对只证明本题标准 Newton 更新 `0→1→0`，与浮点回放分开展示。旧活动记录绑定 owner、活动版本、run id、输入哈希、Runner 版本和课程图版本；版本失配停止引用。

复用 `LearningWorkspace.lab`、`CourseStore.learning_record`、Root Runner 和既有 LabTutor；只新增一个固定活动状态模块及五个 API 操作，没有新表、迁移、模型代理或通用证据框架。活动生成的 run 不自动加载到下方自由实验，避免提前展开完整轨迹；修改初值在自由实验中另存 run，活动的代数结论仍明确限于 `x₀=0`。本轮未调用付费模型，因此只验证助教可获得已有上下文与 UI 引用，未验收真实模型的教学解释质量。

界面同时更新数值实验台中栏：保存记录、停止依据、回放、核对分层排布；共用实验导航吸顶，长记录中栏使用轻量滚动显现并尊重减少动态偏好。保留线性/积分旧表单和右侧固定讨论引用。

本轮验证：`apps/api` 内 `python -m pytest tests/test_newton_activity.py -q` 为 2/2；根目录 `npm test` 为知识 JSON、API 903/903、Web 71/71；`apps/web` 的 typecheck 与 lint 通过（0 错误、10 个既有警告）；停掉开发服务器后 `npm run build:web` 通过。隔离临时 SQLite 与无模型密钥的 API、原项目 Web 页实际操作了预测、逐步观察、解释、修订、刷新、换初值和线性实验保存；滚动导航固定顶部，进入视口的内容最终可见。浏览器的 390px 覆盖设置未生效，因此窄屏交互仍待用可控制视口的浏览器补验；直接答案、跨用户和请求幂等由离线 API 测试覆盖，未做付费模型调用、正式库迁移或部署。

停止条件：若真实模型解释需要标注为数学核验结果，先建立独立评测与人工复核；不能用本轮协议或 UI 测试代替教学收益证据。
