## 已实施的行为

学生本步检查通过固定私有 worker 执行。有界词法规范化和 AST 白名单替代旧字符串 `parse_expr` / `sympify`；输入长度、节点、深度、计算和输出预算受限，不执行学生或模型代码。仅支持实变量 x 与限定函数/指数、常量和操作；新增私有 operation 不扩大模型的两个 native tools 权限。

`VerifyResult` / 保存消息增加 `step-v1`：执行状态、来源、范围、假设、范围完整性、输入/候选摘要、学习资格及未知原因。服务端按当前输入重新绑定候选和操作，校验 worker 返回值，不能只相信 worker 的 eligible 标志。

| 输入/操作 | 当前行为 | 学习记录资格 |
|---|---|---|
| 单一一元等价式、导数候选 | 在受支持的实数范围确定检查；无法证明或找合法反例则未知 | 绑定候选且完整覆盖原命题才允许普通估计 |
| `2x=x+x`、`d(x²)/dx=2x` | 保留隐式乘法/平方表示，正常候选可核对 | 满足上述合同后允许 |
| 仅请求计算导数 | 返回参考结果，学生正确性为空；不再附带“未能验算”的错误提示 | 不写 mastery / mistake |
| `x/x=1` | 保留 x≠0；共同定义域上的等价不等于全实数命题 | 不完整范围不计入 |
| 实数 `sqrt(x²)=|x|` / `Abs(x)` | 显式实数声明可核对；额外前提无法可靠提取时未知 | 必须范围完整 |
| `e^x` / `x**(1/2)` | 有限表示转换；半次幂保留实数范围，求导排除原点 | 代算不计入，候选仍需完整范围 |
| 原函数候选 / 数字 2×2 行列式 | 有界候选检查；不确认积分常数的完整解族 | 仅对应候选合同 |
| 洛必达入口 | 仅判未定式类型，不确认定理所有条件 | 永不作为学生正确性证据 |
| 关键词误区、复杂定义域、多个断言、点值或额外条件 | 线索或未知，不压成错误 | 不自动写学习证据 |

检索维持350ms预算，本步 worker 独立最多5秒（`STEP_VERIFICATION_TIMEOUT_SECONDS`，默认5，上限5），可取父请求剩余 deadline 的较小值。帮助边界前后检查并在执行期间监视；超时、取消和帮助锁变化终止、回收实际子进程。未新建全图总超时；现有上层取消继续有效。固定子进程不是 OS 级内存强隔离声明。

学习写入同时保护 mistake 与普通 mastery，写事务内串行核对帮助资格；确定错误才可持久化已知误区。系统代算、未知、分类和 heuristic 不写。历史正文不改，送入模型时标来源并要求重检；前端历史记录显示范围未记录，聚合历史成绩不精确回算。

聊天、笔记/实验共享会话、学习面板和 ReviewCard 统一展示来源/范围；LLM意见不会替换确定核验。teaching prompt 为 `teaching-v2.6`；默认 typed 工具开关和两个 native tool 合同保持现状，无新表、迁移、依赖。

## 页面文案与首页

使用 copywriting、frontend-design、ui-animation 技能完成有界修改。保留小珞的 AI 身份、静态代码未执行、参考分数与核验限制；不改模型档位值或学习 API。

| 原文字 | 修改后 |
|---|---|
| 推导演绎链路 | 处理步骤 |
| 学子立论 / 重新编辑本步立论 | 你的问题与步骤 / 编辑这条消息 |
| 提笔运思 / 以此步骤重新推导 | 正在生成回答 / 重新生成回答 |
| 极致心流体验 | 展开聊天、隐藏侧栏；浏览器支持时全屏 |
| 格物、轻敏、定理全盘剖析 | 更多/少量/标准思考，说明等待与模型支持差异 |
| 本节课专属笔记、重构数学洞察 | 整理本次笔记、回看错误并修改步骤 |

首页沿用米白、橄榄绿和朱红。新增深色函数曲线区、流动光晕、根位置脉冲、细网格和触控友好的卡片；图形是 x²−2 的真实 Newton 示意，不代表用户记录。动画只持续改变 transform/opacity，静态 blur 不逐帧变化；离屏/隐藏标签暂停，用户可暂停，prefers-reduced-motion 下静止。入口卡片悬停仅 fine pointer/hover，键盘焦点清楚。手机检查发现 overflow:hidden 容器被焦点内部滚动导致标题裁切，改用 overflow:clip 避免该滚动行为。
