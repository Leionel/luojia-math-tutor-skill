# F3：交互数值实验台

> 状态：待实施；目标窗口2026/11/12–12/16；估算5–7开发日。
> 依赖B0及相应方法的独立参考验收；当前root_finding检查提交轨迹，不把它误当成已实现的轨迹生成器。

## 1. 首版教学流程

学生从已有任务或诊断卡进入实验 → 明确函数、方法和目标 → 先写一句预测 → 运行受控算法 → 逐步观察轨迹 → 改一个参数做对照 → 解释差异 → 返回自己的作答任务或开始不同任务的独立检验。

首个实验选Newton循环：`f(x)=x^3-2x+2`、初值0。reference应产生`0→1→0`；画面标出本次循环现象，追问初值与方法条件。不同初值的表现由实际运行返回，不预设所有参数都收敛。

首版同时保留“只检查我提交的过程”入口。自动实验展示参考轨迹，学生手算提交展示学生轨迹，两者来源清楚；实验看到的结果算帮助，不能据此给同题独立成功。

## 2. 三方法范围

| 方法 | 输入与参数 | 展示 | 关键核对 |
| --- | --- | --- | --- |
| Newton | f、初值、容差、迭代上限；后续阻尼/已声明重数变体 | x_k、f(x_k)、步长、导数与停止原因 | 更新规则、近零导数、循环、残差与误差界 |
| 二分法 | f、区间、容差、上限 | 区间、端点值、中点与可验证区间误差界 | 连续性/定义域、变号、不变量、更新与停止 |
| 不动点 | f、g、初值、可选区间、目标 | x_k、g(x_k)、残差与变化趋势 | g映入区间与压缩条件是否可确认；不由有限采样证明一般收敛 |

先固定少量已审实验模板；自定义表达式只开放当前RootExpression支持的运算。缺条件时照实显示未确认；任何稳定图形都不自动证明定理成立。

首版不做全课程动画生成、自由JS执行或通用科学计算Notebook。参数控件由应用代码提供，不依赖模型生成运行脚本。

## 3. 计算与诊断契约

拟新增受控`math_tools/root_runner.py`，复用RootExpression、RootAttempt与diagnose契约；算法循环由可信应用代码实现。生成reference轨迹后独立核对，学生轨迹仍交已有诊断入口，不把两条路径的来源混在一起。

初始上限建议100次迭代、有限表达式大小、单次计算2秒预算、有限输出点数；这些是待测工程预算。接受前核对当前RootAttempt等上限，实际取更严格者。若最坏输入不能在API工作线程可靠终止，则在独立工作进程中执行并硬超时，不能只设置HTTP超时假装计算已停。

`LabRun`建议保存：run_id、task_id、owner/course、method、参数、prediction、runner/oracle/tolerance版本、graph_revision、source_kind=reference_run、trajectory、stop_reason、diagnostic_status、help_exposure、content_hash。跨参数对照使用同一函数与目标快照，允许标明其余参数变化。

结果状态分开：计算完成/失败；停止原因；诊断supported/contradicted/inconclusive/tool_error。达到上限只是停止，不是成功；残差达标不自动满足根误差目标。只有独立可审误差界支持时才展示根误差上界。

建议拟定接口：POST `/api/root-lab/runs`运行受控模板/参数并保存；GET `/api/root-lab/runs/{id}`恢复；POST `/api/root-lab/comparisons`比较两个所属用户且目标相容的run。API返回结构化数据；无需为了实验再次让模型重算轨迹。

## 4. 界面与可达状态

实验台显示参数区、预测输入、逐步轨迹、图形、结论/条件与“继续我的作答”。现有聊天内保留轻量实验入口，较大实验使用独立路由；进入/返回保留原episode。

| 状态 | 产品行为 |
| --- | --- |
| 尚未预测 | 提供可填写预测；不把模板示例当学生回答 |
| 参数不合法 | 就地提示函数/区间/容差问题，保留全部输入 |
| 正在运行 | 固定按钮标签+busy；允许取消；旧结果标旧参数，不混入新结果 |
| 结果未知/缺条件 | 图形可看，结论明确未确认并列缺项 |
| 近零导数/溢出/NaN/循环/上限 | 展示停止处与原因，允许修改参数；不出现成功徽章 |
| 对照目标不同 | 拒绝直接排名，要求统一目标或明确不同条件 |
| 刷新/回到聊天 | 恢复run/参数/预测/来源；不重新计算并覆盖旧证据 |
| 紧凑屏幕/键盘 | 图形与表分区；表可局部滚动；参数可用键盘精确输入 |

函数图继续使用分段曲线，不跨定义域间断点连线。迭代收敛图和函数图标清坐标；若没有真实根参考，不画“真实误差”曲线。已安装Recharts/SVG足够首版，不新增可视化平台。

## 6. 验收与停止条件

未来测试建议`apps/api/tests/test_root_lab.py`及必要前端轨迹/坐标工具测试，覆盖：每种方法解析特例/高精度参考、不同容差、合法替代停止条件、重复运行、取消/硬超时、极端输入、跨用户run、旧参数结果、自动轨迹误计独立、版本变更。

性能验收使用固定设备与代表性/最坏合法输入记录p50/p95和硬终止结果；预算未通过先缩表达式/点数范围或隔离计算，再调整目标，不能宣称当前已有2秒性能。

UI验收：桌面/390px、预测/运行/对照/返回、图形间断与零轴、来源帮助标记、无模型key照常数值计算。教师核对至少一种错误、一种修订、一种合法替代路径/方法；数量为最低内容审阅要求。

关闭实验入口保留已存run和旧聊天；诊断失败只停成绩/结论，不删除学生草稿。独立参考不一致、不能硬终止或自动结果计成独立时，停止受影响实验方法的正式使用，继续其他已验收方法。
